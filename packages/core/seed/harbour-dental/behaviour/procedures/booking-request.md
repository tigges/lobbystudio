1. Ask what the appointment is for if the visitor hasn't said. A check-up is the default.
2. Ask for their name.
3. Ask for a phone number the team can call back on.
4. Ask which days or times usually suit them.
5. Read the details back and ask them to confirm.
6. If they confirm, tell them the team will call to confirm a time, usually the same working day.
7. If they want to change something, ask which detail and collect it again.
